# Going to the End

Платформер, который целиком происходит внутри финальных титров. Один вечер в кино, четыре сеанса, одна жизнь.

**Торопись жить. Жизнь одна.**

## Идея

Ты маленькая светящаяся точка на экране, а по нему снизу вверх ползут титры. Каждое слово — платформа. Нужно спускаться по именам и ролям к карточке **THE END** и не вылететь из кадра.

- Задержишься на слове — титры унесут тебя за верх кадра.
- Упадёшь слишком далеко — вылетишь за низ.
- Каждая смерть — прожог плёнки, «Стоп. Снято.» и новый дубль. Заголовки разделов работают как точки сохранения.
- На каждом сеансе свой **таймер**. Уложился — сеанс в графике.
- На каждом сеансе спрятаны **звёзды ★**. Они засчитываются, только когда доходишь до следующего раздела.

## Программа вечера

| Сеанс | Фильм | Что мешает | Что вокруг |
|---|---|---|---|
| 1 | **Агент без имени**, криминальный триллер | пули: сначала красный лазерный прицел, потом выстрел | красные галстуки, лысые затылки со штрихкодом |
| 2 | **Полый рыцарь**, подземное королевство | гвозди: блеснут наверху кадра и падают вниз | рогатые белые маски, гвозди, синие бабочки |
| 3 | **Последняя орбита**, космическая опера | метеориты; гравитация слабая, прыжки плавные | звёздное небо, планета с кольцом, спутники, ракета |
| 4 | **Going to the End**, наш фильм | осыпающиеся имена, мигающие и качающиеся строки | ничего лишнего, только плёнка |

Первые три уровня — оммажи, а не официальные игры: названия, рисунки и титры придуманы для этой игры.

Во всех фильмах есть общие препятствия: имена с пунктиром осыпаются, мигающие строки гаснут, некоторые строки качаются и везут тебя за собой.

## Пять концовок

Решаются в самом конце вечера по двум вопросам. Успел ли ты на каждом сеансе уложиться в таймер? И сколько звёзд собрал за весь вечер?

| Таймеры | Звёзды | Концовка |
|---|---|---|
| опоздал | меньше половины | экран белеет как в аниме, и тебя сбивает грузовик |
| опоздал | половина и больше | зал опустел, сеанс давно закончился |
| успел | меньше половины | ты пробежал мимо почти всех звёзд |
| успел | половина и больше, но не все | в зале включили свет, но несколько звёзд остались в темноте |
| успел | все | все звёзды вечера летят к тебе, рассвет, и THE END становится THE BEGINNING |

Сколько концовок ты уже видел, показывает главное меню.

## Звук

Гул проектора, а каждое слово при приземлении звучит нотой. У каждого фильма свой тембр. В последнем фильме строка «До · Ре · Ми · Фа · Соль · Ля · Си» играет настоящие ноты.

## Как играть

Открой `index.html` в браузере. Сборка не нужна.

| Клавиши | Действие |
|---|---|
| `←` `→` / `A` `D` | идти |
| `Пробел` / `↑` / `W` | прыжок (короткое нажатие — низкий прыжок) |
| `P` / `Esc` | пауза |
| `M` | звук |
| `N` | новый забег (в главном меню) |

На телефоне под экраном появляются кнопки. Забег сохраняется после каждого сеанса, его можно продолжить позже. Лучшее время и призрак лучшего дубля хранятся отдельно для каждого фильма.

## Версия для Windows

Готовый файл лежит в `dist/GoingToTheEnd.exe`. Это одна программа без установки, около 3,5 МБ: игра и шрифты вшиты внутрь, интернет не нужен. Окно открывается через WebView2, который встроен в Windows 10 и 11. Если WebView2 нет, игра откроется в браузере по умолчанию. Сохранения лежат в `%LocalAppData%\GoingToTheEnd`.

Файл не подписан, поэтому при первом запуске Windows может показать «Windows защитила ваш компьютер». Нажми «Подробнее», затем «Выполнить в любом случае».

Пересобрать после изменений в `index.html`: `desktop/build.sh` (нужны Go 1.24+, python3 с Pillow и curl).
