# Going to the End

Браузерный рогалик о последнем спуске. Под городом колодец в десять ярусов, и на дне его Конец.

## Идея

Главный ресурс — **свет фонаря**. Каждый ход сжигает единицу света, и радиус обзора сужается вместе с ним. Когда фонарь гаснет, тьма начинает отнимать здоровье. Поэтому стоять нельзя: нужно идти вниз, собирать угольки и не тратить ходы зря.

- 10 процедурно генерируемых ярусов, каждый забег уникален
- Смерть окончательна, рекорд глубины сохраняется в браузере
- На 10-м ярусе ждёт **Хранитель Конца**: призывает тени и гасит твой свет. Убей его, и откроются врата `Ω`

## Как играть

Открой `index.html` в браузере. Сборка не нужна.

| Клавиши | Действие |
|---|---|
| `WASD` / стрелки / `hjkl` | ход |
| `Q E Z C` / `y u b n` | диагонали |
| `Пробел` / `.` | ждать |
| `1 2 3` | выбор дара при повышении уровня |
| `Enter` / `R` | начать заново |

Атака — шаг во врага. На телефоне есть крестовина, можно также касаться поля в сторону хода.

## Обитатели и находки

| | |
|---|---|
| `s` Тень | слабая, ходит стаями |
| `m` Пепельная моль | летит на свет издалека, укус ворует 25 света |
| `h` Пустой | крепкий середнячок |
| `w` Призрак | ходит по два шага за ход |
| `H` Оболочка | медленная, но очень сильная |
| `K` Хранитель Конца | финальный босс |
| `*` уголёк | +50 света |
| `!` флакон | лечение |
| `/` осколок | +1 атака |
| `[` оберег | +1 защита |

При повышении уровня выбираешь один из трёх даров: здоровье, атака, защита, длинный фитиль, лечение или свет за убийство.
